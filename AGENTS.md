# Pixload — notas para agentes

- Proyecto Android **Java**, un solo módulo `:app` (AGP 8.13.2, Gradle 8.13, código Java 17, SDK 35); no hay Compose ni archivos de diseño XML. `MainActivity` construye la interfaz y los trabajos JSON; `DownloadService` escribe mediante Storage Access Framework y notifica el progreso.
- Requiere JDK 21 para Gradle (código Java 17) y Android SDK 35. Ejecutar `./gradlew :app:testDebugUnitTest :app:assembleDebug`; para una prueba aislada, `./gradlew :app:testDebugUnitTest --tests 'com.pixload.app.PixivLinkTest'`. El APK queda en `app/build/outputs/apk/debug/app-debug.apk`. Configurar `JAVA_HOME` y `ANDROID_HOME` si no están disponibles en el entorno; no codificar rutas locales en Gradle.
- Pruebas de GIF/MP4 y del índice de galería en dispositivo: `./gradlew :app:assembleDebugAndroidTest`, instalar el APK normal y `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`, después `adb shell am instrument -w -r com.pixload.app.test/androidx.test.runner.AndroidJUnitRunner`. Las pruebas usan un ZIP sintético y preferencias de prueba aisladas; **no** verifican la descarga Pixiv ni SAF real. Antes de reinstalar en un teléfono con datos de usuario, comprobar que `DownloadService` no esté descargando/convirtiendo: reinstalar interrumpe el servicio.
- `PixivClient` usa endpoints AJAX no oficiales. `LoginActivity` comparte cookies de WebView con `PixivClient`; `CookieManager` se envía solo a `pixiv.net`, y las imágenes de `i.pximg.net` requieren `Referer`. Sin cuenta autorizada Pixiv puede devolver metadatos R-18 pero ocultar URLs y responder 404 para archivos. No afirmar que una sesión da acceso a contenido restringido sin verificarlo.
- Convención de guardado: animaciones (solo GIF/MP4), novelas e ilustraciones de **una página original** van directamente a la carpeta elegida como `título.ext` (título Pixiv legible, conservando Unicode y espacios; solo se sustituyen caracteres incompatibles), con sufijo alfanumérico de 4 caracteres solo si colisionan. Obras con 2+ páginas originales crean `título-xxxx/` y mantienen `001.ext`, `002.ext` según índice original, aunque se seleccione una sola página. `MainActivity` decide `grouped`; `DownloadService` resuelve nombres/colisiones y conserva `grouped=true` para trabajos antiguos sin ese campo.
- GIF usa `FastGifEncoder` (paleta 3:3:2/tramado, hasta 960 px); MP4 usa JCodec en `UgoiraConverter` (30 fps, hasta 1280 px). No sustituir accidentalmente el codificador GIF rápido por cuantización por fotograma: la versión anterior tardaba demasiado. Los ZIP de ugoira son temporales en la caché; no se ofrece descarga ZIP en la interfaz.
- `GalleryStore` conserva un historial de descargas completadas mediante URI SAF, incluyendo el último estado heredado si aún está accesible; `DownloadService` registra cada obra al completarla. La pestaña Galería abre imágenes, GIF/MP4 y novelas internamente. El borrado confirmado debe usar `DocumentsContract.deleteDocument` sobre la URI exacta y quitar la ficha solo después del éxito; no confundir el botón para ocultar el progreso con borrar la descarga.
